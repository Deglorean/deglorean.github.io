MIGHT HELP — GITHUB PAGES READY
Primary domain: https://mighthelp.com.au

This repository is ready for direct GitHub Pages publishing from /docs.
No .BAT, PHP, Node.js, database, WordPress or server-side hosting is required.

1. CREATE THE REPOSITORY
------------------------
Create a GitHub repository, for example:

    mighthelp

Upload the CONTENTS of this folder to the repository root.

If using GitHub Free, use a PUBLIC repository for GitHub Pages.

2. ENABLE GITHUB PAGES
----------------------
Repository -> Settings -> Pages

Build and deployment:
    Source: Deploy from a branch
    Branch: main
    Folder: /docs

Click Save.

The public entry file is:
    docs/index.html

The file:
    docs/.nojekyll

tells GitHub Pages to serve the already-built static site without Jekyll processing.

3. SET THE CUSTOM DOMAIN IN GITHUB
----------------------------------
Repository -> Settings -> Pages -> Custom domain

Enter:
    mighthelp.com.au

IMPORTANT:
docs/CNAME is already correct, but GitHub states that a CNAME file by itself
does not configure the custom domain. You must also enter the domain in the
repository Pages settings.

4. DNS FOR mighthelp.com.au
---------------------------
GitHub's documented IPv4 A records for an apex domain are:

    @    A       185.199.108.153
    @    A       185.199.109.153
    @    A       185.199.110.153
    @    A       185.199.111.153

Optional IPv6 AAAA records documented by GitHub:

    @    AAAA    2606:50c0:8000::153
    @    AAAA    2606:50c0:8001::153
    @    AAAA    2606:50c0:8002::153
    @    AAAA    2606:50c0:8003::153

For www.mighthelp.com.au:

    www    CNAME    YOUR-GITHUB-USERNAME.github.io

Replace YOUR-GITHUB-USERNAME with your GitHub username.

Remove conflicting old A/AAAA/ALIAS/ANAME records for the apex and conflicting
www CNAME records, as these can stop GitHub from provisioning HTTPS.

5. VERIFY THE DOMAIN IN GITHUB
------------------------------
GitHub recommends domain verification to reduce takeover risk.

GitHub profile -> Settings -> Pages -> Add a domain

Add:
    mighthelp.com.au

GitHub will give you a TXT record. Add exactly that TXT record at your DNS
provider, verify the domain, and keep the TXT record afterward.

6. ENABLE HTTPS
---------------
After GitHub's DNS check succeeds:

Repository -> Settings -> Pages -> Enforce HTTPS

GitHub will provision the TLS certificate automatically.
