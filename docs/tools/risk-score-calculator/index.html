Risk Score Calculator

Visual risk comparison and control-cost analysis
About this calculator

This calculator uses a Fine-Kinney style risk scoring equation: risk score = probability × exposure × consequence. It was designed as a teaching tool and visual representation of the risk-analysis process, helping users see how probability, exposure, and consequence combine to create a risk score and how controls can change the result.

The cost analysis is a subjective and adaptive decision-support layer. The cost bar upper limit, cost value scale, and expected risk reduction should be adjusted by the user to suit the workplace, budget, production value, and control priorities. It should not be treated as a fixed legal, financial, or engineering standard.
